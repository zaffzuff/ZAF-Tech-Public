# ZAF Tech Node Connector — SoloHost Setup

**Windows helper:** ZAF Tech Node Agent 1.9.9 or later. **SoloHost app:** ZAF Tech Node Connector, publisher zaffzuff.

1. Install the Windows Agent from this repository's latest release on the computer running your Pi Node. Keep Pi Desktop and Docker running.
2. In Pi Desktop open Discover SoloHost Apps. Search for **ZAF Tech Node Connector**, published by **zaffzuff**. This is the public catalog record, not someone else's Node session.
3. Install it and choose a unique application password. Do not use your Pi account password or wallet recovery words.
4. Open the installed app. Confirm the Agent connection and current Node observations. Each installation stores and displays its own data.
5. Pi published availability is optional and requires explicit consent before the Node UUID is sent only to Pi's sync.minepi.com service. This is not a single-day uptime ratio or reward guarantee.

## Explore ZAF Tech

The Pi Browser ZAF Tech entry is https://zaftechpu0455.pinet.com . It provides the Pi ecosystem observatory. The web entry is https://zaf-tech.vercel.app . Promotion links do not transfer application sessions, Node records or credentials.

## Mobile access

Official SoloHost entry: https://solohost.pinet.com . Remote use requires the owner's SoloHost/Pi session and paired computer. A public promotion must not link to a publisher's personal Node session. Seeing a desktop Reachable indicator alone does not prove a phone can complete authentication and load an app.

If the official SoloHost homepage itself returns `Sign in required.`, that response happens before opening Node Connector. App-password, wallet or Node settings are not a remedy for that upstream entry response. Local app functionality and mobile authentication are separate checks.

## Preserve data

Keep the same installation and data volume during updates. Do not uninstall/recreate the app merely to update a logo or troubleshoot a listing icon. The Windows Agent installer preserves its existing installation and history paths.
